## 1. Описание проекта

«Шифр Цезаря» — учебное приложение для демонстрации одного из простейших методов симметричного шифрования. Программа заменяет каждую букву исходного сообщения другой буквой того же алфавита, сдвигая её на заданное количество позиций.

В проект входят две версии приложения:

- `Shifr_Sandakova.py` — настольная программа с графическим интерфейсом на Python и Tkinter.
- `index.html` — веб-версия, которую можно открыть в браузере или опубликовать через GitHub Pages.

## 2. Возможности

- Ввод исходного сообщения.
- Выбор русского или английского алфавита.
- Указание целочисленного ключа шифрования.
- Поддержка положительного и отрицательного ключа.
- Сохранение регистра букв.
- Сохранение пробелов, цифр и знаков препинания без изменений.
- Вывод зашифрованного сообщения.
- Вывод двоичного представления номеров зашифрованных букв.
- Очистка полей в настольной версии.

Для русского алфавита учитывается буква «ё». Нумерация букв начинается с нуля. Для представления индексов используется 6 бит для русского алфавита и 5 бит для английского.

## 3. Принцип работы

Для каждой буквы определяется её индекс в выбранном алфавите. Затем вычисляется новый индекс:

`новый_индекс = (старый_индекс + ключ) % длина_алфавита`

Операция `%` обеспечивает переход в начало алфавита, если сдвиг выходит за его конец. Отрицательный ключ выполняет сдвиг назад.

После шифрования программа выводит двоичное представление индекса каждой зашифрованной буквы. Пробелы и знаки препинания сохраняются как есть.

## 4. Запуск настольной версии

Требуется установленный Python 3. В Tkinter обычно не нужно устанавливать отдельные сторонние библиотеки.

1. Откройте терминал в папке проекта.
2. Выполните команду:

   ```bash
   python Shifr_Sandakova.py
   ```

Если в вашей системе команда `python` не распознаётся, попробуйте `py Shifr_Sandakova.py` в Windows.

## 5. Запуск веб-версии

Откройте файл `index.html` двойным щелчком. Он работает локально в современном браузере и не требует сервера или подключения к интернету.

### Публикация на GitHub Pages

1. Загрузите `index.html` в корень публичного GitHub-репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/(root)`.
5. Нажмите **Save** и дождитесь завершения публикации.

Файл `Shifr_Sandakova.py` можно хранить в том же репозитории как исходный код настольной версии.

## 6. Сборка EXE для Windows

Для создания отдельного исполняемого файла потребуется Windows и Python.

1. Установите PyInstaller:

   ```bash
   py -m pip install pyinstaller
   ```

2. Перейдите в папку проекта и выполните:

   ```bash
   py -m PyInstaller --onefile --windowed --name Shifr_Sandakova Shifr_Sandakova.py
   ```

3. Готовый файл появится в папке `dist` под именем `Shifr_Sandakova.exe`.

Сборку Windows EXE следует выполнять на Windows. В зависимости от настроек системы Windows может показывать предупреждение для самостоятельно собранного приложения.

## 7. Пример

Исходный текст: `привет мир`  
Алфавит: русский  
Ключ: `3`

Каждая буква сдвигается на три позиции вперёд по русскому алфавиту. Пробел остаётся на прежнем месте.
