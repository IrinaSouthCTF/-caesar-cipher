ШИФР ЦЕЗАРЯ — файлы проекта

ВАРИАНТ 1. Запустить в браузере
Откройте index.html двойным щелчком. Интернет не нужен.
Чтобы разместить страницу бесплатно, загрузите index.html в новый публичный GitHub-репозиторий,
затем откройте Settings → Pages → Deploy from a branch → main → /(root) → Save.
После публикации GitHub покажет адрес сайта.

ВАРИАНТ 2. Собрать Windows EXE
1. На компьютере с Windows установите Python с сайта python.org и отметьте Add Python to PATH.
2. Положите исходный файл caesar_cipher_gui.py в эту же папку.
3. Дважды запустите СОЗДАТЬ_EXE.bat.
4. После завершения файл dist\CaesarCipher.exe будет готов к запуску.
Сборку EXE нужно выполнять на Windows. Для Tkinter дополнительные библиотеки не нужны;
PyInstaller скачивается автоматически через pip.

Примечание: шифр Цезаря — учебный алгоритм, не подходит для защиты важных данных.
